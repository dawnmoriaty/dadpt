platform

Entities  Description  
Table  7  –  Entity  Relationship  Diagram  #  Entity  Description  1  Reader  A  user  who  reads  documents  in  the  system.  A  Reader  can  upload  documents,  create  saved  lists,  comment,  vote,  and  report  documents.  Each  Reader  has  a  fullName  and  points  (accumulated  score).  
2  SavedList  A  list  of  saved  documents  created  by  a  Reader.  Each  list  has  a  unique  name  and  belongs  to  a  specific  Reader.  
3  SavedDocument  A  linking  entity  between  SavedList  and  Document,  representing  which  documents  are  saved  in  which  lists.  
4  Document  A  document  uploaded  to  the  system.  It  contains  information  about  the  uploader,  title,  and  premium  status.  A  Document  may  belong  to  an  Organization  and  is  categorized  by  Domain  and

Specialization.  
5  Report  A  violation  report  created  by  a  Reader  for  a  document.  It  contains  the  report  reason.  
6  Comment  A  comment  made  by  a  Reader  on  a  document.  It  contains  the  comment  content.  
7  Vote  A  rating  (upvote/downvote)  given  by  a  Reader  to  a  document.  It  contains  a  value  (+1  or  -1).  
8  Domain  A  field  or  industry  used  to  classify  documents  (e.g.,  IT,  Healthcare,  Economics).  It  has  a  name  and  a  code.  One  Domain  can  contain  multiple  Specializations.  
9  Specialization  A  sub-field  within  a  Domain  used  for  detailed  document  classification  (e.g.,  Web  Development  under  IT).  It  has  a  name  and  a  code.  
10  Tag  A  label  used  to  tag  documents  to  support  searching  and  categorization.  Each  Tag  has  a  unique  name.  
11  Organization  An  organization  or  institution  in  the  system.  It  can  own  multiple  documents  and  contains  a  name  and  contact  email.  
12  Business  Admin  A  business  administrator  of  the  system.  Has  the  authority  to  assign  Reviewers  to  premium  documents  that  require  review.  Identified  by  fullName.  
13  Reviewer  A  person  responsible  for  reviewing  premium  documents.  Has  a  fullName  and  credentials  (professional  certificates  or  qualifications).  Receives  review  requests  from  the  Business  Admin.  
14  Review  Request  A  request  created  by  a  Business  Admin  to  assign  a  document  to  a  Reviewer  for  evaluation.  Contains  documentId,  reviewerId,  and  expiry  date.  
15  ReviewResult  The  result  of  a  document  review  submitted  by  a  Reviewer.  Contains  the  decision  (isAccept),  a  review  report  file,  and  review  comments.
